WZ UW IntraLex

Wyszukiwarka i baza aktów wewnętrznych Uniwersytetu Warszawskiego oraz Wydziału Zarządzania UW. Wyszukuj pełnotekstowo lub zadawaj pytania w języku naturalnym z wykorzystaniem AI.

Jak korzystać z narzędzia
1. Zakładka Wyszukiwarka — wpisz frazę (np. „rekrutacja", „pensum", „środki trwałe"), opcjonalnie zawęź organ i rok. Wyniki sortowane wg trafności (BM25).
2. Zakładka Zadaj pytanie (AI) — wpisz pytanie w języku naturalnym. Narzędzie znajdzie najbardziej trafne akty i wyśle je do wybranego modelu AI, który odpowie z cytatami źródłowymi.
3. Do trybu AI potrzebujesz klucza API (OpenAI, Anthropic lub Google) albo lokalnego serwera (Ollama).
4. Po otrzymaniu odpowiedzi możesz kliknąć Wyjaśnij prostszym językiem lub zadać pytanie uzupełniające — AI zachowa kontekst rozmowy.
Aktualizacja bazy aktów
Baza jest ładowana z pliku data/akty.json. Aby pobrać najnowsze akty, uruchom w terminalu:
python -m src.ingestion.monitor_uw && python -m src.ingestion.wz_uw && python -m src.export_json
